# Perro galáctico

Composición animada en HTML para HyperFrames: un perro astronauta atraviesa una nebulosa, con planeta, anillos y brillo cósmico. Está diseñada para una duración de **5 segundos** en formato 1920 × 1080.

## Renderizar a MP4

Requisitos: Node.js 22 o superior y FFmpeg instalado.

```powershell
npm install
npm run verify
npm run render
```

El resultado se genera en `renders/perro-galactico.mp4`.
